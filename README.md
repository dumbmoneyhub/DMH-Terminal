## Özellikler

- 1×1, 2×1, 2×2 düzende gerçek T-View grafikleri; tek oturum
- Çevrimdışı sembol kataloğu, kategori filtresi, favoriler
- Piyasa haber akışı
- Uygulama içi güncelleme
